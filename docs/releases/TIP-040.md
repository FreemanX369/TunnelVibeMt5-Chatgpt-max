# TIP-040 — Live MT5-2 observations

## Tools

| Tool | Source | Returns |
| --- | --- | --- |
| `get_terminal_live_state` | Running MT5-2 via Python MetaTrader5 IPC | Account, connection, last ping and positions/orders counts |
| `get_account_snapshot` | Same on-demand accessor | Same snapshot for account-focused calls |
| `list_live_charts` | Win32 chart child windows belonging to the exact configured MT5-2 executable | Unique `chart_id` (HWND), symbol, timeframe, visibility, client size |
| `capture_live_chart(chart_id)` | Win32 client-only `PrintWindow` of a verified visible chart | MCP `ImageContent` (`image/png`) and small metadata |
| `read_terminal_journal(source, limit)` | The fixed MT5-2 data root | Bounded tail of `journal` or `experts`; default 100, maximum 200 lines |
| `inspect_terminal(include_logs)` | The sources above under one native lease | Account, connection, charts, installed EA file counts, optionally both bounded logs |

Examples: call `inspect_terminal(include_logs=true)` to inspect the terminal in one request; call `list_live_charts`, then pass the desired unique `chart_id` into `capture_live_chart`. Two XAUUSD M1 charts remain distinct. The selected chart must be visible in the interactive Windows session. The image response has a PNG content block; it is not embedded as base64 text in the log or metadata.

The account accessor calls only `initialize`, `terminal_info`, `account_info`, `positions_total`, `orders_total`, and `shutdown`. It requires the fixed installation to be **already running** before initialization; it validates both the returned installation path and data root. A failed binding aborts the request. When disconnected, financial fields and current ping are null. `ping_last_us` is the last recorded ping in microseconds; `ping_ms` converts that value only while connected. Account trade flags describe what MT5 reports; use bounded Journal context when investigating the cause of disabled trading.

Every IPC/chart/log request takes the existing native MT5 execution lease with a 2-second wait limit, so it cannot overlap a tester/compile handoff. There is no persistent telemetry EA, timer, tick handler, or polling. Screenshot runs in a disposable process with a 5-second timeout, a 3-megapixel capture bound and an 8 MB PNG response bound. The captured client area must pass chart/process identity checks before and after rendering; errors fail closed. Journal reads only the latest daily log, at most 128 KiB, and masks common credentials and account numbers before returning lines. Installed EA inventory counts filenames under the fixed `MQL5/Experts` directory on request, with a 10,000-file scan bound and no file-content reads. `.ex5` is a file count, not the number of distinct production EAs.

## Proven limits and deviation

The installed Python MetaTrader5 package exposes account and terminal properties but does not expose chart enumeration or MQL5 `ChartScreenShot()`. The local MT5 MCP chart and screenshot tool schemas have not been established. TIP-040 therefore uses Windows chart child windows and an isolated Win32 capture rather than claiming native `ChartScreenShot()` access. `list_live_charts` reports EA attachment and indicators as `UNKNOWN`; window titles and saved `.chr` profiles cannot prove them. If the interactive MT5 GUI does not expose verifiable chart child titles, chart listing/capture fails without substituting a saved profile or whole-desktop screenshot. Precise EA/indicator inventory needs a separately verified in-terminal `ChartGetString(chart_id, CHART_EXPERT_NAME)` path.

## Acceptance

The unit suite covers running-installation binding, wrong-data-root rejection, disconnected-account handling, ping conversion, unique chart selection, PNG `ImageContent`, log bounds and redaction. A Windows-only smoke test checks the live running idle MT5-2 account/network, GUI charts, and one actual PNG. A passing cross-platform suite alone is not a live screenshot acceptance. Release requires the Windows smoke test in the interactive VPS session and refreshed model-visible connector catalog for A/B/C.
