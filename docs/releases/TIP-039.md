# TIP-039 — Generic PowerShell tool

## Change

Adds the model-visible `backend_run_powershell` tool to VibeMQL5 Bridge. The tool executes a caller-supplied PowerShell script on the VPS as the Windows identity running the Bridge. It is available through the shared Bridge catalog, so connected A, B, and C sessions receive the same capability after their connector schemas are refreshed.

The tool requires `confirm=true` on every call, accepts scripts up to 32,768 characters, defaults to a 60-second timeout, and caps execution at 300 seconds. It captures at most 32 KiB each from stdout and stderr while continuing to drain the process streams. The short PowerShell bootstrap is encoded on the command line; the separately encoded user script is passed through stdin, so user script text does not appear in process arguments or get written to a temporary file. The tool removes environment variables whose names look like keys, tokens, passwords, credentials, or secrets, and redacts several common credential patterns in returned output.

Example read-only call:

```json
{
  "script": "$PSVersionTable.PSVersion.ToString()",
  "confirm": true,
  "timeout_seconds": 30
}
```

Commands share the existing FIFO mutation and native MT5 leases. The audit file records operation IDs, a non-authenticated connection key, command hashes, exit status, output byte counts, and timing; it does not save the command text or stdout/stderr. The returned receipt is not persisted to disk.

## Security and identity limits

This is an unrestricted shell endpoint, not a sandbox. It can read or change anything the Bridge Windows identity can access, start detached processes, alter MT5 files/settings, or affect the tunnel. The Bridge deployment may run as an Administrator. Environment filtering and common-pattern redaction reduce accidental disclosure; they do not prevent an arbitrary script from reading or encoding secrets. Do not ask the tool to print credentials or DPAPI contents.

The stdio tunnel does not provide a security-grade ChatGPT account ID. A, B, and C therefore cannot be independently authenticated, restricted, or attributed by this tool. All sessions using this shared Bridge get the same PowerShell privilege. `confirm=true` is an invocation guard, not an account authorization mechanism.

This release does not make GUI or interactive MT5 control reliable from background sessions, and it does not change the fixed terminal policy (`MT5-2`). The new tool only supplies process-level PowerShell execution.
