## 058B acceptance

* Wire `fleet.wire/1`: exact POST paths `/fleet/v1/pair`, `/fleet/v1/heartbeat`, `/fleet/v1/poll`, `/fleet/v1/results`. Define a finite header grammar for device/public key/route/timestamp/nonce/signature. Reject duplicate headers/JSON keys, unknown fields, invalid UTF-8, booleans as numbers, nonfinite values, query/path aliases and oversized bodies. Sign a versioned domain separator, method, exact path, SHA256 of exact transmitted body, device, public key, route, timestamp and nonce. Header names canonical; values unambiguous. A logical operation digest excludes transport nonce/timestamp; fresh signed retry preserves the committed logical receipt.
* Real Ed25519 verification precedes admission. Recheck registered key/ACTIVE route/current generation and reserve nonce atomically at the selected control mutation. Initial pairing signs with the grant-bound key (initial route 0 on wire only); consume grant, nonce and route update atomically, including a fresh-nonce retry of the existing logical pair receipt. No caller `verified=true`, arbitrary SQL callback or IDs-as-authentication. Admin operations remain a separate explicitly authenticated owner surface and operation namespace. Gateway control errors stay sanitized.
* HTTPS service is a single bounded writer/event owner, never started by each MCP process. Outbound client requires configured HTTPS origin and a normal CA/hostname-verifying SSLContext; no `verify=False` or insecure option. The server uses configured certificate/private-key paths; no auto provisioning. Use explicit required policies for request/response sizes, polling, deadlines, clock/freshness, sessions, pending queue/results, fan-out and capacities. Do not call synthetic fixture values production-qualified defaults.
* Heartbeat/session handshake recognizes conflicting concurrently active installation sessions; generation is retained across ordinary reconnect. Copied key material cannot prove physical uniqueness. Revoke/key rotation/re-pair invalidate old route admission. Enrollment/private-key bootstrap source uses fresh Ed25519 key, create-exclusive restrictive file and no secret logging; existing key is not overwritten or included in Git/backups/clone packaging.
* Restore fences dispatch; old valid DB anti-rollback is not claimed without independent node witnesses. Persist routes/replay and distinguish online transport from SDK/session readiness. Keep durable domain journals in 060 for effectful commands. B performs no native/SDK effect.
* Tests: real ephemeral Ed25519 sign/tamper/replay/restart/key/route/pair races, temporary-CA real HTTPS hostname/CA failures, outbound heartbeat/poll/result integration, bounded request errors/no secrets and source regression. Publish useful gateway/node startup entry points and operator config example with placeholders. No actual endpoint, VPS, account or key access.

## 059 acceptance

* Finite read operations are state/account only. A command freezes exact device/route/terminal/generation, operation/request hash and observation deadline before delivery. Node requires its own device ID, exact fresh local binding and generation. Never remove a route field to call legacy local targeting and never fallback to MT5-2 after selection.
* Poll/result binds device, route, node session, command nonce/ID, requested target and request digest. Revalidate before accepting a result. Duplicate identical results return the same receipt; changed/cross-node/stale/late results are retained/quarantined or denied and never returned as current successful observations.
* Enforce a total monotonic broker deadline, bounded fan-out/queue/body/rows, scoped failures and per-node serialized IPC. A timed-out read does not authorize a second still-running IPC lifecycle. Production local adapter retains `LIVE_ATTACH_ONLY_UNPROVEN` until the exact preventive no-start/SDK/process qualification exists; labeled synthetic test adapters may exercise positive routing. Registry/heartbeat data is not live account evidence.
